# Image Super-Resolution with GAN (Real-ESRGAN)

A Jupyter Notebook project that uses the pre-trained **Real-ESRGAN** model to upscale low-resolution images by **4×**, and compares the result with classic **bicubic** interpolation using **PSNR** and **SSIM** metrics.

**Tech stack:** Python · Jupyter Notebook · PyTorch · Real-ESRGAN · OpenCV · scikit-image · Matplotlib

---

## How It Works

Quality metrics such as PSNR and SSIM need a high-quality reference image. To make the comparison fair, the experiment is built like this:

1. Take a sample photo and crop it to a centered square, then resize it to **512×512** (the *reference*).
2. Downscale the reference to **128×128** (the *low-resolution input*).
3. Upscale the input back to 512×512 with two methods:
   - **Bicubic** interpolation (traditional baseline)
   - **Real-ESRGAN** (GAN-based super-resolution)
4. Compare both results against the reference using PSNR and SSIM.

The model is **not trained from scratch**. The notebook uses the pre-trained `RealESRGAN_x4plus` weights, which are downloaded automatically on first run.

## Getting Started

1. **Clone the repository**

   ```bash
   git clone https://github.com/YOUR_USERNAME/Gan.git
   cd Gan
   ```

2. **(Recommended) Create a virtual environment**

   ```bash
   python -m venv venv
   # Windows
   venv\Scripts\activate
   # macOS / Linux
   source venv/bin/activate
   ```

3. **Install Jupyter and PyTorch**

   ```bash
   pip install jupyter torch torchvision
   ```

4. **Open the notebook**

   ```bash
   jupyter notebook GAN_Image.ipynb
   ```

5. **Run all cells from top to bottom.** The first cell installs the remaining dependencies, and the model weights (`RealESRGAN_x4plus.pth`, ~64 MB) are downloaded automatically into the `weights/` folder.

> If you get an import error after the install cell, restart the kernel and run the cells again from the beginning.

## Using Your Own Image

1. Copy your image (JPG or PNG) into the project folder.
2. In the last code cell of the notebook, change `input_path`:

   ```python
   input_path = "your_image.jpg"
   ```

3. Run the cell. The upscaled image is saved to `results/my_image_enhanced.png`.

PSNR and SSIM cannot be computed for your own image unless you also have the original high-resolution version of it.

## Results

Metrics from the sample experiment (128×128 → 512×512):

| Method        | PSNR (dB) | SSIM   |
|---------------|-----------|--------|
| Bicubic       | 33.064    | 0.9211 |
| Real-ESRGAN   | 29.073    | 0.8669 |

**Note:** Bicubic scores higher on these metrics, which is a well-known effect. PSNR and SSIM reward pixel-by-pixel similarity to the reference, while GAN models like Real-ESRGAN are designed to generate sharper, more realistic-looking details that may not match the original pixel for pixel. Compare the images visually in `results/` as well, not only the numbers.

## Troubleshooting

| Problem | Solution |
|---------|----------|
| `No module named 'torchvision.transforms.functional_tensor'` | The notebook already includes a compatibility fix (cell 2). Make sure you run it before importing `realesrgan`. |
| Black output image on GPU | Some GPUs (e.g. GTX 16xx series) produce black images with `float16`. The notebook uses `half=False` and falls back to CPU automatically. |
| Out of memory | In the model setup cell, change `tile=0` to `tile=256`. |
